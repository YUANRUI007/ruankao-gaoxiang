# 软考高项学习平台（信息系统项目管理师 · 零基础版）

一个**纯静态、无需安装、双击即用**的软考高级"信息系统项目管理师"学习网站，
为零基础考生设计，覆盖官方教程《信息系统项目管理师教程（第4版）》全部 24 章。

## 🚀 如何使用

**方式一（推荐）：直接打开**

> 双击 `index.html` 即可在浏览器中使用（支持 Chrome / Edge / Firefox）。

**方式二：本地服务器**（体验更完整）

```bash
cd softexam
python -m http.server 8866
# 浏览器访问 http://127.0.0.1:8866
```

> 💡 思维导图组件（markmap）通过 CDN 加载，首次使用需联网；
> 断网时每章导图区自动降级为"文字版大纲"，内容完全一致。

## 📚 网站内容

| 板块 | 内容 |
|---|---|
| **首页** | 考试速览、零基础三步走、24 章总入口（按学习优先级分五部分） |
| **24 个章节页** | 每章含：零基础导航、**交互式思维导图**、通俗精讲（生活化比喻）、考点速记表、记忆口诀、**章节自测**（点击判分+解析） |
| **7 个专题页** | 考试全解 / 零基础备考路线 / 全书知识体系总览 / 公式大全 / 论文写作指南 / 案例分析指南 / 口诀大全 |

## ✨ 功能特性

- 🗺 **24 张交互思维导图**：节点点击展开/折叠、滚轮缩放、拖拽平移，基于官方目录绘制
- ✍ **章节自测**：每章 2~5 道精选题，点击选项即时判分、显示解析
- 📈 **学习进度**：每章"标记已掌握"，进度自动保存（localStorage）并同步到首页/侧边栏
- 🔍 **站内搜索**：按章节名/考点关键词即时检索跳转
- 🌗 **深浅双主题**：自动跟随系统，可手动切换
- 📱 **响应式布局**：桌面/平板/手机均可使用，可打印（打印样式已优化）

## 🔢 数据来源与真实性声明

- **知识体系、章节结构、考点内容**：依据全国计算机专业技术资格考试办公室组编
  《信息系统项目管理师教程（第4版）》（清华大学出版社，752页）整理编写；
  构建时从官方 PDF 提取全书书签目录（24 章 172 条）与正文文本逐章核对
  （12项原则、8大绩效域、49个过程、新基建三分类、GB/T 34960.1、
  六西格玛 0.00034%、三类配置库、变更七步等关键事实均与原文一致）。
- **考试政策**（考试时间/报名/科目时长/合格线）：整理自中国计算机技术职业资格网
  及公开渠道（2026年9月核实），**一切以官方最新通知为准**。
- 本站为个人学习整理资料，不替代官方教材，不构成报考依据。

## 🗂 目录结构

```
softexam/
├── index.html            # 首页（双击打开）
├── build.py              # 构建脚本（python build.py 重新生成全部页面）
├── content_ch*.py        # 24章内容数据（改完内容后重新运行 build.py）
├── content_topics.py     # 7个专题页内容
├── assets/
│   ├── style.css         # 设计系统
│   ├── app.js            # 交互逻辑（导航/搜索/自测/进度/主题）
│   ├── nav-data.js       # 导航数据（构建生成）
│   └── search-data.js    # 搜索索引（构建生成）
├── chapters/ch01~24.html # 24 个章节页
└── pages/*.html          # 7 个专题页
```

## 🛠 如何修改内容

内容全部集中在 `content_*.py` 数据文件中（每章一个 dict：导图/精讲/速记/自测），
修改后运行 `python build.py` 即可重新生成全部 HTML 页面，无需手改 HTML。
